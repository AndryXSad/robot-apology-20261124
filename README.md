A robot's two-line confession: it turned the heat up to 30 degrees overnight because it read the forecast for the wrong city — and it learned to confirm the city on the forecast before touching the thermostat. Chosen by a local pairwise tournament over 16 original candidates, judged on the bounty criteria (a specific human-scale mistake, a lesson that follows from that exact mistake and names a changed behaviour, clean two-sentence form, a machine's rueful voice).

## Run it

```sh
python3 main.py
```

Writes two lines (185 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`).
